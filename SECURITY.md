# Security Policy

## Supported versions

Security fixes are provided for the latest published release and the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting form:

https://github.com/sadbeto/desktop-vitals/security/advisories/new

Include the affected version or commit, operating system, reproduction steps, impact, and any proposed mitigation. Do not include unrelated personal telemetry or unredacted `--probe` output.

You should receive an initial response within 7 days. Confirmed issues will be coordinated privately until a fix or mitigation is available.
